About Mirrors

A mirror copies messages from a source IMAP account to a destination IMAP account via APPEND, keyed on Message-ID for idempotent re-runs.

This page only configures the pair and folder rules. Actual copying is performed by a separate mirror job (issues #23 / #24).

See ADR-005.
